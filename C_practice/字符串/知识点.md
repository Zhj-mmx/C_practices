# C语言 字符串 基础知识点讲解（初中生友好版）

> **先记住一句悄悄话**：在 C 语言里，根本没有真正的“字符串类型”，它就是一串**排好队的字符**，最后站着一个**看不见的哨兵** `\0`。

---

## 1. 什么是字符串？

**通俗解释（初中生版）：**
想象一串糖葫芦。竹签上穿着一个个山楂（字符），最后一个山楂后面，竹签会多出来一截尖头，告诉你“吃到这里就没了，别再往前咬了”。

- **山楂** = 字符（比如 `'H'`, `'e'`, `'l'`, `'l'`, `'o'`）
- **竹签尖** = 空字符 `'\0'`（反斜杠零，是一个 ASCII 码为 0 的字符，看不见但实际存在）

所以字符串 `"Hello"` 在内存里实际存储的是：  
`'H'` `'e'` `'l'` `'l'` `'o'` `'\0'` —— 一共 6 个位置，最后一个位置是哨兵。

---

## 2. 怎么把字符串存起来？—— 字符数组

C 语言没有专门的“字符串”变量，只能用 **字符数组** 来装这一串山楂。

| 写法 | 解释（初中生版） |
| :--- | :--- |
| `char name[10];` | 申请了一根能穿 **10 个山楂** 的竹签（最多存 9 个有效字符 + 1 个哨兵） |
| `char name[] = "Tom";` | 让编译器自己数，自动申请 4 个位置（`T`,`o`,`m`,`\0`），刚刚好 |
| `char name[5] = "Tom";` | 有 5 个位置，多余的会全部填上 `\0`，有点浪费但很安全 |

**⚠️ 关键区分：**
- `'A'` —— 这是**单个字符**，用单引号，就一个山楂。
- `"A"` —— 这是**字符串**，用双引号，包含 `'A'` 和 `'\0'` 两个东西。

---

## 3. 怎么输入输出字符串？

| 函数 | 比喻与用法 | 致命弱点 |
| :--- | :--- | :--- |
| `printf("%s", str)` | **喊名字**：把竹签上的山楂从第一个开始念，念到哨兵就停。 | 安全，不会念过头。 |
| `scanf("%s", str)` | **扫条形码**：从键盘读一个单词，但**遇到空格就停**，读不了“Tom Hanks”。 | 输入超过数组长度会撑爆竹签（缓冲区溢出） |
| `fgets(str, size, stdin)` | **安全收快递**：指定最多收几个字符，能读空格，还会把最后的换行符也收进去。 | 需要手动去掉多余的换行符 |

**💡 安全做法：**
```c
char name[20];
fgets(name, sizeof(name), stdin);  // 最多读19个字符，留1个给'\0'
```

## 4. 你的字符串有多长？—— `strlen` vs `sizeof`

这俩经常让人混淆，请看比喻：

- **`strlen(str)`** = 数一数**有效山楂**有几个（不包括竹签尖 `\0`）
- **`sizeof(str)`** = 量一量**整根竹签**占多少厘米（包括尖头 `\0`，如果竹签还有空余也算进去）

**例子：** `char name[10] = "Tom";`  
- `strlen(name)` → `3` （只有 T、o、m 三个）
- `sizeof(name)` → `10` （竹签本身长度固定为 10 个格子）

> 使用 `strlen` 需要 `#include <string.h>`

---

## 5. 常用字符串“外挂工具”—— `<string.h>` 里的四大金刚

你需要像背乘法口诀一样熟悉它们，因为它们不能直接用 `+` `=` 来操作字符串。

| 函数 | 作用 | 初中生比喻 | 危险提醒 |
| :--- | :--- | :--- | :--- |
| `strcpy(目标, 来源)` | **复制粘贴** | 把第二根竹签上的山楂，原样穿到第一根竹签上（包括尖头）。 | 第一根竹签必须够长！ |
| `strcat(目标, 追加)` | **接尾巴** | 把第二根竹签的山楂，接到第一根竹签的末尾，自动覆盖原来的尖头。 | 目标空间必须能放下合并后的全部山楂！ |
| `strcmp(串1, 串2)` | **比大小** | 像查字典，从头开始比字母的 ASCII 码。相等返回 `0`，串1大返回正数，串1小返回负数。 | 不要用 `==` 比较字符串，那是比较竹签的地址！ |
| `strlen(串)` | **数山楂** | 前面讲过，数到尖头为止。 | 没有尖头会数到别人家去，导致死循环。 |

**安全升级版（推荐使用）：**  
`strncpy`, `strncat`, `strncmp` 可以指定最多操作多少个字符，防止捅娄子。

## 6. 指针与字符串的“爱恨情仇”

你可以用一个 **字符指针** 直接指向一个字符串：

```c
char *p = "Hello";
```

这时 `p` 指向一串写死在**只读区域**的山楂串，你**只能看不能改**。如果尝试 `p[0] = 'h';`，程序可能会当场暴毙。

**结论：**  
- 如果这个字符串**以后要修改** → 用字符数组 `char str[] = "Hello";`  
- 如果只是**拿来用用，不修改** → 用指针 `char *p = "Hello";`

用指针遍历字符串很优雅：
```c
while (*p != '\0') {
    putchar(*p);
    p++;  // 竹签往前推一格
}
```

## 7. 新手必踩的坑（提前帮你填平）

| 坑 | 为什么会掉进去 | 怎么爬出来 |
| :--- | :--- | :--- |
| **忘记留 `\0` 的位置** | `char s[5] = "Hello";` 长度不够，没地方放哨兵，字符串会“放飞自我” | 数组长度至少为有效字符数 + 1 |
| **用 `==` 比较字符串** | `if (str1 == str2)` 比较的是两根竹签的位置，不是山楂的内容 | 必须用 `strcmp(str1, str2) == 0` |
| **输入带空格** | `scanf("%s")` 见到空格就罢工 | 用 `fgets` 或 `gets_s` |
| **修改字符串常量** | `char *p = "ABC"; p[0] = 'X';` | 用数组 `char p[] = "ABC";` |
| **`strcat` 空间不足** | 目标数组装不下合并后的串，直接踩坏邻居家的内存 | 用 `strncat` 并算好总长度 |

---

### ✨ 记住这几点，C 语言字符串就拿下了一半：

- 字符串本质是**带 `\0` 的字符数组**。
- 凡是操作字符串的函数，几乎都在 `string.h` 里。
- 一定要**时刻关心数组长度**，否则分分钟“竹签捅破纸”。
- 比较内容用 `strcmp`，不用 `==`。
