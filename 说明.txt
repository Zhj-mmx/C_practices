# 练习1：Hello World
最基础的C程序，熟悉基本语法结构
编译: gcc 01_hello_world.c -o hello && ./hello

# 练习2：基本数据类型和运算
练习变量声明、基本算术运算、输入输出
涉及: int, float, char 类型

# 练习3：条件判断 (if-else)
练习比较运算符和条件控制
应用场景: 成绩评级、奇偶数判断

# 练习4：循环结构 (for/while/do-while)
练习各种循环的使用
包含: 嵌套循环 - 九九乘法表

# 练习5：数组基础
一维数组的声明、初始化和遍历
应用: 求和、平均值、最大值查找、数组反转

# 练习6：函数基础
函数的定义、调用和参数传递
应用: 阶乘计算、数组最大值查找

# 练习7：字符串和字符数组
字符串的基本操作
函数: strlen, strcat, strcpy, strcmp
应用: 字符串反转、大写转换、回文检查

# 练习8：指针基础 (进阶)
指针的概念、声明和基本使用
内容: 指针与数组、动态内存分配、const指针

# 练习9：结构体
结构体的定义和使用
内容: 结构体数组、嵌套结构体、结构体指针

# 练习10：综合练习 - 成绩管理系统
命令行版成绩管理小程序
功能: 添加、显示、查找、统计

# 推荐学习顺序
1. Hello World - 熟悉环境
2. 基本类型 - 理解数据
3. 条件判断 - 控制流程
4. 循环 - 重复操作
5. 数组 - 处理数据集合
6. 函数 - 代码复用
7. 字符串 - 文本处理
8. 指针 - C语言精髓 (重点)
9. 结构体 - 自定义数据类型
10. 综合项目 - 实战应用

# 小贴士
- 多动手敲代码，不要只看
- 遇到错误不要怕，编译器错误信息很有帮助
- 使用printf调试程序状态
- 理解内存的概念对学习指针很重要
- 每个练习都可以扩展功能，比如添加更多功能

祝学习愉快！ 🌱
